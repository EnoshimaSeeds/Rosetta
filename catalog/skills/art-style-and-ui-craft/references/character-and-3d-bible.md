# 角色美术圣经、服装高定剪裁与 3D/Live2D 前置拆解

构思原创角色、立绘生图或准备送入 Tripo 3D / Unreal Engine 5.8 / Live2D 时，必须同时立住**剪影语言、真裁缝级服装结构与物理材质参数**，彻底告别“毫无穿脱逻辑的 AI 塑料奇幻服与乱飘丝带”。

---

## 1. 剪影语言与 60-30-10 明度焦点

- **主导几何基元与纯黑剪影测试**：先定角色的形体基调（圆弧柔美流动 / 方块稳重可靠 / 锐角斜线凌厉灵动）；把角色整体涂黑后，仅凭发廓、领型、袖摆或标志背负物须在 1 秒内辨识身份。
- **60-30-10 配色与去色明度检视**：`60%` 主衣料稳住基调 + `30%` 内搭/衬里拉开明度差 + `10%` 高纯度焦点色集中锁定在**头肩胸三角区**（瞳色、领口胸针、耳坠、衣领嵌线）；转黑白灰度后脸部与领口须保持最高对比度。

## 2. 服装廓形建筑学与垂坠物理（Garment Construction & Drapery）

想让角色服装像真正的高定设计师或顶级概念原画师手笔，核心在于**「结构硬支撑 vs 流体软垂坠」的反差对比**与**真实缝制工艺细节**：

1. **软硬廓形碰撞（Stiff Tailoring × Fluid Drape）**：
   - **结构支撑区**：立裁挺括肩线、鲸骨束腰胸衣（Boned bodice）、军装风衣防风枪挡（Storm flap）、挺括箱型褶（Box pleats）、硬质皮具武装带；
   - **流体垂坠区**：`45°` 斜裁真丝（Bias-cut silk，贴合曲线如水流动）、多层半透明欧根纱/雪纺透叠（Layered sheer organza）、瀑布荷叶边（Cascading ruffles）与水母裙摆；
   - **铁律**：同一套造型必做软硬对比（例如：**硬朗羊毛军装短斗篷 + 柔若星河的斜裁渐变百褶长裙**），避免全身材质软硬趋同导致轮廓与层次混淆。
2. **三层穿衣叙事结构（Skin-Out Layering）**：
   - **贴身基础层（Base）**：细亚麻立领衬衫、高领罗纹针织、梭织蕾丝内衫（交代生活质感）；
   - **身份核心层（Mid）**：收腰马甲、斜交门襟束衣、不对称背带或腰封（锁住腰线比例）；
   - **戏剧外廓层（Outer）**：单侧披肩长风衣、开衩礼服外袍、廓形机能夹克（制造动态迎风大剪影）。
3. **让生图与建模一眼显贵的真实裁缝工艺词（Sartorial Micro-Vocabulary）**：
   - **立体合身**：省道收腰（Tailored darts）、裙摆三角插片（Godet / Gore insets，转身或奔跑时裙摆自然扇形绽开）、腋下菱形活动插布（Underarm gussets，保障挥剑/大幅动作符合解剖逻辑）；
   - **边缘与里外细节**：撞色嵌线滚边（Contrast piping）、双道明线压缉（Twin-needle topstitching）、风衣走动时翻露的异色暗纹里布（Contrast jacquard lining peek）；
   - **真实扣具（拒绝悬浮固定）**：牛角扣（Horn buttons）、珍珠母贝包扣（Mother-of-pearl covered buttons）、中式盘扣（Frogging）、古铜日字扣或 Fidlock 磁吸快拆机能扣。

## 4. PBR 物理材质参数与下游工业管线交接门禁

- **PBR 材质锚点**：定稿时标明各部件 `Albedo` 基色、`Roughness`（如粗纺羊毛 `0.85`、重磅真丝缎 `0.38`、哑光机能尼龙 `0.65`、拉丝做旧黄铜 `0.32`）与 `Metallic`（织物 `0` / 纯金属件 `1`）。
- **转入 Tripo 3D / Blender / Unreal Engine 5（衔接 `game-3d-live2d-pipeline`）**：单独输出**中性漫反射打光的 A-Pose / T-Pose 正交三视图**，拆离大面积遮挡躯干的外披风或半透明薄纱层单独建模，执行五项入引擎体检。
- **转入 Live2D 立绘拆层**：提前标清长发前后片、翻领、披肩、袖口与手指的遮挡层级，所有被遮挡底层区域预留完整补底（Inpainting）出血余量。
