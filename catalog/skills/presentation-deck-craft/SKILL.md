# 高审美演示架构、多光谱令牌与模块化页型

本卡内置四套经过 W3C 实算校验的 WCAG 令牌与页型骨架，采用**「选色板令牌 + 按需拼装模块化页型 + 跨卡文案/工程联动」**的轻量结构，覆盖学术答辩、产品路演、美术设定集、科普图鉴与叙事画册等全场景（适用 `.pptx`、在线演示稿 / HTML Slides、HTML 演示与静态 PDF）。

---

## 0. 默认主控权约定（与外部 `ppt-master` 协同时）
- 课程答辩、Keynote 路演、美术设定集、科普图鉴与叙事画册，**默认由本卡掌管叙事节奏、版面构成与色彩/线条令牌**。
- 若用户额外挂载外部工具 `ppt-master`（MIT），默认**仅作为底层可编辑矢量编译（SVG → DrawingML）、静态质检与视频导出引擎**调用，不启动其自带的多角色模板流程（除非用户明确点名按其原生全流程制作）。

---

## 2. 按场景读取模块化页型与文案联动

开工前按任务性质读取对应的按需蓝图，避免把学术汇报模板硬套进创意/科普演示：

- **学术答辩 / 论文批判性汇报** → 必读 `references/academic-deck-patterns.md`（双声部色板纪律、10 种标准学术页型、批判性汇报骨架与自查清单）。
- **产品路演 / 美术设定集 / 科普图鉴 / 诗意画册** → 必读 `references/visual-deck-patterns.md`（画廊出血开场页、角色/物件设定档案卡、关键数字对比页、时间线、趣闻单主体页、关系网与致谢出处页 + 70/20/10 策展细线叠印法则）。
- **叙述性中文文案强制联动**：只要演示包含中文故事、科普讲解、趣味图鉴、人物评述或页面串联，**动工前必同时启用独立技能卡 `natural-chinese-prose`**（避免连续标题套用同一句式模具、百科词条转述口吻与行尾劈词）。
- **单页信息密度上限**：一页聚焦单一主视觉锚点或最多 3–4 条精炼短句；常规论证页正文控制在 45–70 词（中文约 80–120 字）以内，边距留白 ≥ 画幅 `8%`。

## 3. 素材署名与裁图洁净度底线

含外部插画、视频截帧、摄影或社区二创素材的演示，交付前须逐项核验：
1. **逐页出处与末尾致谢**：引用他人作品须在对应页脚写清作者名、作品/来源标识（如论文引文或视频编号），并在尾页汇总来源与授权边界（如 `CC BY-NC-SA 4.0` 的署名、非商用与相同方式共享要求）。
2. **裁图四角洁净度**：检查裁切后的图片边缘与四角，严禁残留原平台角标水印半字、原视频字幕/对话框碎片，或合照裁切时邻近人物误入边缘的残影。
3. **白底立绘融底**：深色或暖纸底页面放入白底立绘时，优先抠透底或在 HTML/Slides 纸本相框内叠加 `mix-blend-mode: multiply` 融底，避免暗底上浮现刺眼的纯白矩形贴纸感。

---

## 4. 动效节制原则（仅支持动效的介质生效）

当输出格式为 在线演示稿 / HTML Slides、交互网页或带切换的 `.pptx` 时遵守以下四条（静态 PDF 直接跳过）：
1. **短促不抢戏**：单页入场分拍总时长 ≤ `1.0s`；需要变化节奏时优先调整色彩与密度，不加快运动速度或使用弹跳/炫技飞入。
2. **切换承载语义**：同一章节内翻页使用柔和淡入（Fade），跨章节/切换角色时使用平顺推入（Push/Slide），让观众凭动效感知结构层级。
3. **点击揭示留给包袱**：仅将真正的反转、揭晓答案或关键数据对比设为点击揭示，不把普通背景正文拆得支离破碎。

---

## 5. 全介质渲染终审与 `[仅 .pptx]` 工程项

- **全介质通用铁律（不可省略）**：无论输出 `.pptx`、在线演示稿 / HTML Slides、HTML 还是静态 PDF，交付前必须导出实际渲染画面或 PDF **逐页目视过一遍**，核查图片裁切露边、水印残留、文字溢出、遮挡与中文双音节劈词（如 `余 / 音`、`大 / 小姐`、行尾孤字）。
- **`[仅 .pptx]` 工程约束**：生成可编辑 `.pptx` 时联动 `office-craft-suite` 及其 ppt 工程蓝图；正文不低于 `18pt`、图注不低于 `13pt`；未确认本机装有思源字体时，中文无衬线回退 `Microsoft YaHei`，衬线回退 `SimSun`；优先调用本机 PowerPoint 导出预览核查真机折行。非 `.pptx` 介质（如 在线演示稿 / HTML Slides / 网页）直接沿用宿主原生尺寸与版式安全区规则，不生搬 `pt` 与 PowerPoint 检查项。
