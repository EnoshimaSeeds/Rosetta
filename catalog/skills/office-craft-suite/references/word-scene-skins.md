# Word (.docx) 与 PDF 场景光谱、精细线条构成与防孤页工程规范

> **来源与许可声明**：本文档在文档结构化生成、样式表隔离与真机防错思路上参考自开源仓库 [anthropics/skills](https://github.com/anthropics/skills)（Apache-2.0），并结合 Windows Word（Office 16.0）中文字体与行网格实测独立编写为中文场景排版蓝图。

文档排版需同时避免**场景错配**（将日常课程练习做成过度装饰的宣传单，或将文学画册套入行政公文版式）以及**滥用高饱和底纹色块**。开工前须先确定场景基准（创意、画册与设定集类文档可结合 `art-style-and-ui-craft` 派生色温与版式）。

| 皮肤代号 | 适用场景 | 字体与 Windows 保底链 | 线条与色彩边界 | 版式与空间核心要求 |
| :--- | :--- | :--- | :--- | :--- |
| **`student-plain`** | 课程练习、开卷测验、周作业、读书笔记 | 纯黑 `#000000`；英文 `Times New Roman` 11–12pt，中文 `思源宋体 → 宋体 (SimSun)`，1.15–1.5 倍行距 | **零彩色横幅、零伪造学校抬头、零底纹卡片框** | 2.0–2.5 cm 常规页边距；清晰加粗分级标题；仅保留简洁页码 |

| **`story-book`** | 短篇小说、星辰/水色绘本册、人文随笔集 | 正文 `思源宋体 → 宋体` 10.5–11.5pt，英文 `Georgia / Garamond`；1.65–1.8 倍舒展行距 | 温润墨色（`#22201E` 或星夜深靛 `#17253B`）配单点低饱和强调色，禁用公文色带 | 推荐 `A5` 或宽边距 `A4`（左右 ≥ 2.8 cm）；章首留白配外粗内细双细线或极细星轨纹样；文风联动独立技能卡 `natural-chinese-prose` |

## 2. 文档精细线条与留白手法（Linework & Whitespace Discipline）

1. **以精密线条替代厚重底色框**：引用段、章节题头或设定卡片优先采用**单侧 `1.5pt` 竖向墨线 + 留白缩进**、**上下 `0.5pt` 贯穿发丝线（Hairline Rules）**，或**外 `1.5pt` + 内 `0.5pt` 古典双线页框（Double-Rule）**，避免用整块重色矩形填充背景。
2. **页眉页脚结构感**：页眉可用 `0.5pt` 细横线承托两端对齐的「章节名（左） × 等宽页码/档案号（右）」，保持版面清透。

## 3. Word (`.docx`) 与 PDF 生成工程铁律（真机 Office 16.0 验证）

1. **禁止手工拼装裸 OOXML / ZIP**：必须使用成熟库（`python-docx`、`reportlab.platypus` 等），所有段距与缩进写入样式表，禁止使用连续空行回车分页。
2. **字体回退必写系统保底**：Windows 默认不预装思源字体，代码设置 `eastAsia` 时必须显式指定 Windows 原生保底字体（衬线用 `SimSun` 宋体，无衬线用 `Microsoft YaHei` 微软雅黑）。
3. **严防 LibreOffice 与 Windows Word 的行网格分页漂移（`w:snapToGrid` 孤页陷阱）**：
   - Windows Word 默认启用行网格吸附（`w:snapToGrid`），配合真实 `SimSun` 字宽，每页实际容纳行数比 Linux LibreOffice 少 **10%–15%**，容易导致章节末尾多出近乎空白的孤页。
   - 对策：定版页数图文册要么显式关闭 `snapToGrid` 并设固定磅值行距（`WD_LINE_SPACING.EXACTLY`），要么每章预留 ≥ 15% 页底安全余量；本机具备 Word COM 时优先调用真机导出 PDF 复核。
4. **表格四项稳态属性与 ReportLab 上下标**：Word 表格显式双写总宽与列宽、数据行开启 `cantSplit`、跨页表头开启 `tblHeader`、底纹使用 `CLEAR` 禁用 `SOLID`；ReportLab 上下标须使用 `<sub>` / `<super>` 标签或嵌入完整 TTF 字体防止缺字方框。
