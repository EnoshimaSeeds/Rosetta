# 流程调度口令、多线程认知分流与涉外文书准则

## 1. 双档位协作调度口令
- **「走一遍流程」**：停止仅凭经验快速作答，主动调取当前任务领域对应的技能规范与校验脚本（如文献核验、LaTeX 引文检查、架构安全审计、设计令牌校验），完整执行 **需求边界确认 → 规范实现 → 实测验证** 后交付成品。
- **「多视角独立复核」**：启动多维度独立审查流程（**先查硬缺陷再深挖切面，仅凭可复现证据下结论，不作凑数点评**）：
  - **必查项**：先独立排查 `[BLOCKER]` 级实质缺陷（权限越界、数据覆盖或丢失、并发竞态、未核实事实与逻辑断裂）；
  - **动态深挖**：按当次课题（代码架构、实验方案、论文论证或界面可用性）分配独立审视切面，可复现问题尽量附最小复现脚本；
  - 汇总为分级缺陷单（`[BLOCKER]` / `[MAJOR]` / `[MINOR]`），清零全部 `BLOCKER` 并经用户裁决分歧项后定稿。

## 2. 多线程认知分流排期（Cognitive Triage）
当多项任务并行过载时：
1. 按 **「硬截止日（Hard Deadline）× 不可替代度」** 拆分为三栏：**今日唯一主攻** / **本周排期池** / **暂缓冻结项**；
2. 将最棘手的大任务拆解为 **15 分钟内可启动的第一步具体动作**，降低启动阻力。

## 3. 合同与协议审阅（Contract Redline Review）
逐条核查以下六类核心风险，输出四列表（`原条款编号与摘录 | 风险等级 | 风险说明 | 可直接替换的修订措辞`），绝不覆盖原件：
1. **权责对等性**：单方变更权、单方解约权与不对等违约金；
2. **费用与退费条款**：隐性附加费、自动续费扣款、退费限制与押金退还时限；
3. **知识产权归属（IP Ownership）**：背景知识产权隔离与职务作品范围；
4. **保密与竞业限制（NDA / Non-Compete）**：地域、期限与行业范围是否过宽；
5. **模糊免责与兜底词**：如 “reasonable efforts”、“at sole discretion” 等单边弹性表述；
6. **管辖法律与争议解决**：适用法域与仲裁/诉讼成本。

## 4. 学术申请文书与正式英文联络邮件
- **事实核验铁律**：成绩、排名、奖项与科研经历严格核对原始记录，绝不夸大成果或将“计划进行”表述为“已完成”。
- **正式英文邮件结构（150–220 词精炼模板）**：
  - **Subject**：清晰具体（`[Topic/Role] — [Key Identifier] — [Your Name]`）；
  - **Opening & Context**：1–2 句说明身份与联络缘由（BLUF）；
  - **Core Ask / Value**：分段或短要点说明具体诉求与关键佐证；
  - **Next Step & Sign-off**：明确可行的时间窗口或下一步动作，礼貌收尾（`Kind regards` / `Best regards`）。
