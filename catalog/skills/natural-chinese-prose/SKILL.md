# 自然汉语语感、展示文案节奏与去人机味规范

大模型在被禁止“塑料吹捧套话”（极其、赋能、不是A而是B）后，常向反方向矫枉过正，滑入**「翻译腔冷峻电报体」**、**「百科词条转述腔」**或**「监控探头流水账」**。凡涉及演示稿（PPT/Slides）叙述文案、科普图鉴、绘本画册、网页导语、项目汇报与个人陈述，动笔与终审须执行以下五条准则。

---

## 1. 防双向人机味：既去“塑料油腻”，也去“冷硬电报体”

| 病灶类型 | 典型失真表现 | 自然汉语修正方向 |
| :--- | :--- | :--- |
| **塑料吹捧与假排比** | 高频堆砌“极其 / 赋能 / 场域 / 降维打击”；反复使用“不是 A，而是 B”“不仅是…更是…” | 删去空洞副词与对称口号，直接写清具体事实、感官细节或因果对比 |
| **无铺垫单字缩略 / 生造词** | 把黄铜提灯硬省成单字“灯”、生造章节名“铜架”；把“绕过礁石外侧”直译省成“礁的环外” | 现代汉语依赖双音节节奏与清晰中心语；无上下文铺垫时不硬删音节，改写为“那盏黄铜提灯”、“绕过礁石外侧” |
| **英文语法直译与搭配错位** | 英文插入语硬塞两逗间（`推开那扇门，漆成深绿色的，朝里看了看`）；*stop one breath* 直译“我停一口气”；把 *curled around* 误写成意为避开的“暖风绕过窗台” | 形容词归位或拆成自然分句（`推开那扇深绿色的木门朝里看了看`）；核对汉语动词真实语义方向（改用“屏住一口气”、“暖风轻轻拢住窗台”） |
| **监控探头式句号流水账** | 连续多句全是 8–14 字主谓宾短句（`沉重的木箱卡在门槛上。站长把值班本塞回口袋，弯腰去挪箱子。`），或同类条目反复套用 `有人让他 X，他就 Y` | 在关键发现与动作之间补上人的真实停顿、直觉或情绪转折；长短句交替，动作急促处用短句，叙述与情绪处放开气口 |
| **预告片碎句与冷淡句号癖** | 疑问句硬打句号（`有人问他，船呢。`）；抽干主语写成舞台提纲；半文半白夹生公文（前句仿古文、后句突变为现代清点口吻） | 疑问语气老实用问号；保留自然主语衔接并统一时代语域，不把古今词法生硬拼接 |

## 2. 演示文案、科普图鉴与轻松叙事节奏

做 PPT、Slides、科普盘点、角色图鉴或网页导语时，最容易写得像资料汇编。下笔前守住四条节奏线：

1. **别用百科词条口吻先铺背景再概括笑点**：不要写“这句话出现得太频繁，成了吐槽名句，后来变成经典台词”这类第三人称综述；直接落一个具体反差场景，让笑点自己冒出来。
2. **包袱与反转放在最后一口气，禁挂预告路标**：删除“反转来了：”“网友顺势喊出”“中文网络有条不成文的规律”以及连续两段“……于是……”等综述路标词；如果一页核心是某个搞笑绰号或误认，别在标题里提前把后半截反转剧透掉。
3. **并列卡片保持体例一致、句式有变化**：同一页的两三张小卡，小标题不要一张用台词引号、另一张用四字概括词；正文切忌连续三张全按同一主谓骨架机械排比。
4. **长篇演示保留一条连贯讲述者声线**：多页展示（尤其是科普、图鉴、画册与分享型演示）需要页间串联——可用贯穿全篇的讲述者短注脚或承上启下的过门句把各页串成一次对话，避免前半篇生动、后半篇退回孤立条目清单。

## 3. 破除开放命题的「温柔童话同质化」

当用户仅给出几个抽象意象词（如“灯塔、旧信、雨夜、摆渡人”）而未限定情节时：
1. **先排除第一反应套路**：大模型默认最易滑向“陌生人偶遇 → 发现对方默默等待多年 → 默默留下信物离开 → 次年风平浪静”的无痛童话模板。动笔前先主动排除这一默认剧本，寻找更有具体质感的人物处境、性格棱角或意料之外的细节切口。
2. **用具体器物动作代替抽象抒情**：少写概括性的高尚动机，多写具体可触摸的生活细节（如潮湿粘连的纸页、生锈打滑的门闩、垫在桌脚下的折旧船票），并确保细节合乎日常物理常识。

---

## 4. 跨媒介交付的「唯一事实底本（Canon Lock）」

同一故事或项目同时输出网页、Word 文档与 PPT 画册时：
- **动工前先锁死 5 行事实锚点表**（核心地名/门名、出场人物身份、时间线、关键信物的最终位置与动作）。
- 不同媒介只调整**叙事详略与镜头切面**（如 PPT 抓视觉转折瞬间，Word 展开完整前因后果），**严禁给三个端各编一套互相打架的细节**。

---

## 5. 展示级中文排版防劈词与标题节奏

1. **禁止连续标题套同一语法模具**：画册、网页分节或幻灯片连续多页的标题，严禁复读同一字数与词法骨架（如四张设定卡连用四次 `A、B 和 C`，或连续三页同句式断行）。主动变换句型结构与节奏重心。
2. **大字号标题不加末尾句号**：除完整人物引语外，独立展示标题（H1/H2、封面与分章标题）末尾不加句号 `。`。
3. **严防行尾劈裂双音节词与孤字换行**：大字号引语、窄栏卡片或标题必须核查实际渲染折行位置（网页启用 `text-wrap: pretty` 或微调栏宽/措辞），严禁把完整双音节词劈在两行首尾（如 `设 / 计`、`编 / 辑器`、`在下 / 面`），或让单个虚词/标点孤立落到下一行（如 `方案 / 吗？”`、`结果的 / 人。`）。

## 6. 常规项目汇报提醒

写日常进度说明、缺陷复核或交接备忘时，直接交代“改了什么、验证结果是什么、遗留什么边界”，避免绕弯寒暄或套话总结；出稿前默读一遍，确保接近真人自然呼吸语序。
