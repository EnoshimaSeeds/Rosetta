# 科研与论文配图

画要进论文、报告或答辩的数据图时启用（Python 或 MATLAB）。一张图只回答一个问题，读者不看正文也能读懂坐标轴。

## 1. 先定尺寸，再画图
- 按最终印刷宽度作图，不要画大了再缩：单栏约 8.8 cm（3.5 in），双栏约 18 cm（7.2 in）。具体数值以目标期刊或课程模板为准。
- 最终尺寸下字号 7–9 pt，线宽约 0.8–1.2 pt。

## 2. 随附脚本与样式文件说明（`scripts/`）
- **Python Matplotlib 样式表（`scripts/rosetta-sci.mplstyle`）**：
  - 用法：`plt.style.use("<skill_dir>/scripts/rosetta-sci.mplstyle")`（适用于 Matplotlib ≥ 3.5）。
  - 关键默认配置：单栏默认画布 `3.5 × 2.6 in`、`constrained_layout = True`、矢量 PDF/PS 嵌入 TrueType Type 42 字体（`pdf.fonttype = 42`）、位图导出 `600 dpi`、内置 Okabe-Ito 色盲安全色循环。双栏图在加载样式后覆盖 `figsize=(7.2, ...)`。
- **MATLAB 出版级导出函数（`scripts/save_pub_fig.m`）**：
  - 用法：先执行 `addpath('<skill_dir>/scripts')`，再调用 `save_pub_fig(gcf, 'fig2', 8.8, 6.5)`。
  - 参数定义：`fig`（MATLAB Figure 对象）、`filename`（不含扩展名的输出路径前缀）、`widthCm`（默认 `8.8`）、`heightCm`（默认 `6.5`）；自动统一字体字号、线宽并同时写出矢量 `.pdf` 与 `600 dpi` `.png`。
  - 环境前提与验证边界：依赖 **MATLAB R2020a 及以上版本**（`exportgraphics` 函数）；**该脚本尚未在本地 MATLAB 环境中实测，首次使用时须核验导出文件**。

## 3. 颜色
- 分类数据用 Okabe-Ito 色盲安全色，顺序：黑 #000000、蓝 #0072B2、朱红 #D55E00、绿 #009E73、橙 #E69F00、天蓝 #56B4E9、紫红 #CC79A7、黄 #F0E442（黄色在白底上弱，放最后）。
- 连续量用 viridis 这类感知均匀的色图；有正负的量用发散色图，并把零点对到中间色。不用 jet 或 rainbow。
- 颜色之外再加一层区分（线型、标记形状），保证黑白打印也能分辨。
- 同一份文档里，同一个样品或条件始终用同一种颜色。

## 4. 坐标轴与标注
- 轴标签 = 物理量 + 单位，如 `Stress (MPa)`、`|Z| (Ω)`；对数轴要写明。
- 误差棒或阴影在图注里说明是 SD、SEM 还是置信区间（CI），并给出样本数 `n`。
- 图例不压数据；系列不超过 3 条时优先在线旁直接标注。
- 论文图不在图内放标题，结论写进图注；幻灯片里的图可以把结论放在页标题。
- 多面板用小写 a、b、c 标在左上角，各面板共用的坐标轴只标一次。

## 5. 诚实作图
- 柱状图的数值轴从 0 开始；截断坐标轴要有明显标记。
- `n` 小的时候把每个数据点画出来，不要只画均值柱。
- 平滑、去基线、归一化都要在图注或方法里写明。
- 不同面板之间要比较大小时，用相同的坐标范围。

## 6. 导出
- 线图导出矢量格式（PDF 或 SVG）；带照片或热图的导出不低于 300 dpi，线条为主的位图用 600 dpi。
- PDF 内嵌字体（样式文件已设为 TrueType 42 型）。
- 保存生成这张图的脚本和数据，文件名与图号对应。
