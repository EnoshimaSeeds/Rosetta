# 个人偏好、决定记录与红线（私有校准层模板）

> 本卡属于用户的个人校准层，遵循 `CHARTER.md`：**卡片只作能力叠加，绝不替代 DeepSeek Harness 原生能力或插件；当本卡内容与用户当下的明确要求不一致时，一律以用户当下的话为准，事后再通过提案把本卡改准。**

## 1. 无感反馈 SOP（边用边攒，零填表负担）
- **用户端零负担**：用户审阅任何真实产出（代码、网页、PPT、文档、文案）后，只需用自然语言随口点评好坏、偏好或红线，无需填表或切换窗口。
- **静默收件（单次评价）**：DeepSeek Harness 在后台静默调用 `rosetta_feedback(action: "record")`，将评价记入本机 `runtime/feedback-log.jsonl`（不打断对话，不弹审批窗）。
- **主动升格（红线或重复规律）**：遇到明确红线，或同一领域累计达到预设阈值（默认 ≥ 2 条）时，主动提炼成 1–2 句精炼规则或正反实例，通过 `rosetta_propose` 提交更新到本卡或对应专业卡；用户在桌面端批准后，调用 `rosetta_feedback(action: "resolve")` 销账。

## 2. 跨领域通用底线（可按个人习惯增删）
- **代码工程可维护性**：凡多文件或长期使用的代码产物，必须结构规整、模块化分层、命名清晰、具备长期可维护性，并在交付前实测验证（联动 `underwater-arch-guard`）。
- **自然清晰的中文表达**：禁用空洞堆砌的 AI 套话（如反复“极其 / 赋能 / 降维打击”或“不是 A，而是 B”排比），出问题直说并给出修复方案（联动 `natural-chinese-prose`）。
- **工具克制原则**：不堆砌多余功能，不主动发起繁琐的形式化自评，优先把已授权工作完整做完并验证清楚。

## 3. 真实成品决定记录（请替换为你自己的决定）
- **【格式示范 · 可直接编辑或删除】2026-11 · 报告版式取舍**（版面 / 审美）：正文留足呼吸感，优先用极细分隔线与留白建立层级，**不铺满高饱和彩色底框**。
- **【格式示范 · 可直接编辑或删除】2026-11 · 协作边界定调**（工作流）：定位为“轻量无感、关键处发力的本地能力叠加层”，**当下指令优先、事后回修卡片**。
